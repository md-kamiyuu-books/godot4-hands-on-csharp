# godot4-hands-on-csharp

書籍「**手を動かして学ぶGodot 4 入門 ― Unity経験者のためのハンズオンガイド(C#版)**」(カミユウ 著)のサンプル素材配布リポジトリです。

## 使い方

1. このリポジトリをダウンロードします(「Code」ボタン →「Download ZIP」、または `git clone`)
2. 本文の各節の指示に従って、`assets/` 配下の素材ファイルを自分のプロジェクトへコピーします

## 収録素材

| フォルダー | 内容 | 使用する節 |
| --- | --- | --- |
| `assets/tiles/` | タイル素材 3 枚(各 64x64) | 4.3 タイルマップ |
| `assets/backgrounds/` | パララックス用の背景素材 3 枚(各 1152x648) | 4.5 パララックス |
| `assets/sprites/` | コマアニメ用スプライトシート 2 枚 | 5.1 2Dスプライトアニメ |
| `assets/sounds/` | 効果音(WAV)・ループ BGM(Ogg) | 5.5 音を鳴らす |
| `assets/models/` | アニメーション入り 3D キャラクターモデル(glb) | 6.2 3Dモデルとアニメーション |
